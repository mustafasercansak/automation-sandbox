## Highlights

- **Deleted-element false heals, three shipped guards (#370, #375):**
  - **Per-component name gate.** When the stale locator had a name, the winning candidate's
    `NameScore` must clear `SimilarityWeights.MinimumNameScoreWhenNamed` on its own,
    independent of the weighted total. The `Balanced` and `Conservative` profiles set `0.30`;
    `SimilarityWeights.Default` ships disabled. HandBrake `Balanced` false-heal `9.3 % → 7.6 %`,
    precision `90.7 % → 92.4 %`, recall unchanged.
  - **Repository ownership reconciliation.** `SelfHealingEngine.ReconcileAgainstRepository`
    (opt-in, default off) re-resolves every other authored locator against the same captured
    tree before accepting a confident match, and declines the heal as `ownership-conflict`
    when the winning candidate is already another locator's confident identity. Heuristic-only,
    no extra LLM traffic.
  - **Per-component descendant gate (#375).** `SimilarityWeights.MinimumChildSignatureSimilarity`
    (`0.50` on `Balanced` / `Conservative`, disabled on `Default`). `UiElementSnapshot.Capture`
    now records the multiset of an element's direct child `ControlType`s; when the stale
    locator was a container, the winning candidate must still hold matching child types. Catches
    an unnamed panel healing onto a structurally identical sibling that holds something else —
    the one residual the other two guards can't reach. Optional snapshot field; a no-op on
    pre-#375 snapshots and on leaf locators.
  - **Combined:** deleted-element false heals across the committed ablation datasets go from
    `40 %` (HandBrake) / `28 %` (ShareX) at the shipped default to **zero on both**, with zero
    genuine-rename verdict flips. See `benchmark-calibration.md` §14/§15 and
    `integration-existing-suite.md` §5.

## Known Limitations

- **Calibration:** higher confidence thresholds reduce false heals, but the magnitude does not transfer between applications. Calibrate against your own UI history; the shipped `MinimumConfidence` is `0.50`.
- **Accuracy:** the three per-component guards (#370, #375) drive deleted-element false heals to **zero on both committed fixtures** at no auto-heal recall cost. This is not an absence detector — it is three targeted gates (label contradiction, another locator owns the candidate, the container's contents changed). A deleted element that heals onto a leaf control no other test uses and whose label happens to match would still slip through; none occurs on HandBrake or ShareX, but a third application could resurface one. Perceptual-hash and LLM-pairwise absence signals remain unmeasurable on the current fixtures (`benchmark-calibration.md` §15).
- **LLM providers:** covered by mocked-HTTP unit tests; the nightly workflow gates one known ground-truth agreement scenario against independent providers. Release creation does not run a live gate. `llm-smoke.yml` is a manual single-endpoint diagnostic after GitHub Models' retirement (#44).
- **Platform:** desktop automation is Windows-only (FlaUI / UIA3). The heuristic engine and the web path are cross-platform and verified on Linux in CI. Linux desktop discovery via AT-SPI is tracked in #17.
