## Highlights

- **Deleted-element false heals, two shipped guards (#370):**
  - **Per-component name gate.** When the stale locator had a name, the winning candidate's
    `NameScore` must clear `SimilarityWeights.MinimumNameScoreWhenNamed` on its own,
    independent of the weighted total — the `0.20`-weighted name signal is otherwise blended
    away. The `Balanced` and `Conservative` profiles set `0.30`; `SimilarityWeights.Default`
    ships disabled. Measured: HandBrake `Balanced` false-heal rate `9.3 % → 7.6 %`, precision
    `90.7 % → 92.4 %`, auto-heal recall unchanged.
  - **Repository ownership reconciliation.** `SelfHealingEngine.ReconcileAgainstRepository`
    (opt-in, default off) re-resolves every other authored locator against the same captured
    tree before accepting a confident match, and declines the heal as `ownership-conflict`
    when the winning candidate is already another locator's confident identity. Heuristic-only,
    no extra LLM traffic. Measured across the committed fixtures: deleted-element false heal
    `19 % → 2 %` (HandBrake), `23 % → 7 %` (ShareX), with identical genuine-rename recall.
    See `benchmark-calibration.md` §14 and `integration-existing-suite.md` §5.

## Known Limitations

- **Calibration:** higher confidence thresholds reduce false heals, but the magnitude does not transfer between applications. Calibrate against your own UI history; the shipped `MinimumConfidence` is `0.50`.
- **Accuracy:** the per-component name gate and repository ownership reconciliation (#370) cut deleted-element false heals to low single digits on both committed fixtures at no auto-heal recall cost, but reconciliation is a contested-candidate guard, not an absence detector. The *uncontested* residual — a deleted element that heals onto a control no other locator in the suite owns — is unchanged and mathematically bounded by the structural score overlap; a non-structural signal for it is spiked in #375.
- **LLM providers:** covered by mocked-HTTP unit tests; the nightly workflow gates one known ground-truth agreement scenario against independent providers. Release creation does not run a live gate. `llm-smoke.yml` is a manual single-endpoint diagnostic after GitHub Models' retirement (#44).
- **Platform:** desktop automation is Windows-only (FlaUI / UIA3). The heuristic engine and the web path are cross-platform and verified on Linux in CI. Linux desktop discovery via AT-SPI is tracked in #17.
