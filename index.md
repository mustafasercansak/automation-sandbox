# 🚀 Automation Sandbox

![CI](https://github.com/mustafasercansak/automation-sandbox/actions/workflows/ci.yml/badge.svg)
![Release](https://img.shields.io/github/v/release/mustafasercansak/automation-sandbox?include_prereleases)
![NuGet](https://img.shields.io/nuget/v/AutomationSandbox.SelfHealing.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)

An open-source **locator healing** and **intent-driven test generation** engine for Windows desktop (FlaUI/UIA3) and web (Playwright). A deterministic structural scorer decides first — zero tokens; an LLM is an opt-in fallback behind an independent-agreement quorum, never the decision maker. Every heal is written to an auditable report.

**Açık kaynak bir locator iyileştirme ve niyet-güdümlü test üretme motoru** — Windows masaüstü (FlaUI/UIA3) ve web (Playwright). Önce deterministik bir yapısal skorlayıcı karar verir (sıfır token); LLM yalnızca opsiyonel bir yedek, bağımsız-anlaşma çoğunluğuyla kapılı, asla karar verici değil. Her iyileştirme denetlenebilir bir rapora yazılır.
